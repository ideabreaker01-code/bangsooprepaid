선불폰 셀프개통 준비물과 신청 순서

처음 선불폰을 신청한다면 요금제, 본인확인, 유심을 차례로 확인하세요. 준비가 되면 공식 신청 화면으로 이동하고, 진행이 어려운 경우에만 상담을 이용하면 됩니다.

1. 어떤 신청을 하려는지 확인하세요

  • 신규 가입: 새로운 전화번호로 가입하는 경우입니다.
  • 번호이동: 사용하던 번호를 유지하면서 통신사를 옮기는 경우입니다. 공식 안내에는 기존 통신사의 인증과 번호이동 사전동의가 필요하다고 설명돼 있습니다.
  • 요금제 변경: 기존 회선을 유지하면서 상품을 바꾸는 경우입니다. 신규 가입이나 번호이동과 신청 방식이 다릅니다.

기존 고객의 KT 선불396·459 요금제 변경에는 추가 데이터가 제공되지 않습니다. 다른 상품의 변경 조건은 해당 상품 안내에서 확인하세요.

2. 개통 준비물 3가지

① 본인 신분증

안면인증에 사용할 주민등록증 또는 운전면허증을 준비하세요. 공식 안내에는 개통 시 신분증 인증과 안면인증을 진행한다고 설명돼 있습니다. 다른 신분증으로 신청하려는 경우에는 가능한 인증 방법을 먼저 확인해주세요.

② 본인 명의 휴대폰과 본인인증 수단

본인 명의 휴대폰을 준비해야 합니다. 카카오·토스·PASS·신한·KB국민 등 안내된 인증 수단으로 본인 명의 인증을 완료할 수 있는지 확인하세요. 앱을 설치한 것만으로 인증 준비가 끝난 것은 아닙니다.

안면인증에 사용할 휴대폰 카메라가 정상 작동하는지도 확인해주세요. 인증 수단을 사용할 수 없거나 본인 명의 휴대폰 준비가 어려우면 신청 전 상담으로 가능한 방법을 확인하세요.

③ 선택한 통신망에 맞는 유심

KT / K망과 LG U+ / L망 중 사용할 통신망을 먼저 정하고, 해당 망에서 사용할 수 있는 유심을 준비하세요. 유심을 아직 구매하지 않았다면 공식 구매 안내에서 호환 제품을 확인하세요.

유심 포장에 표시된 일련번호를 신청 화면에 정확히 입력해야 합니다. 공식 안내에는 잘못 입력하면 개통되지 않거나 다른 유심이 개통될 수 있다고 설명돼 있습니다.

3. 요금제 선택부터 개통까지

  1. 사용량에 맞는 요금제를 고르세요. 사이트의 요금제 페이지에서 필요한 데이터, 일반 통화량, 통신망을 선택하면 상품을 비교할 수 있습니다. 데이터 소진 후 속도와 영상·부가통화 한도도 함께 확인하세요.
  2. 준비물 3가지를 확인하세요. 신분증, 본인 명의 휴대폰과 인증 수단, 통신망에 맞는 유심을 준비합니다.
  3. 공식 신청 화면에서 신청하세요. 사용할 통신망과 신규 가입 또는 번호이동을 선택하고, 본인확인과 상품 선택을 진행합니다. 이 사이트에서 선택한 요금제 정보는 공식 화면으로 자동 전달되지 않으므로 다시 선택해야 합니다.
  4. 최종 요금과 가입 조건을 확인하세요. 기본 데이터, 추가 제공 조건, 통화 범위와 이용 요금 등을 확인한 뒤 신청을 진행하세요. 이 가이드만으로 개통 가능 여부가 확정되지는 않습니다.
  5. 개통 완료를 확인한 뒤 유심을 장착하세요. 공식 안내에 따라 진행하고, 바로 통화가 되지 않으면 휴대폰을 2~3회 재부팅해보세요. 계속 이용이 어렵다면 상담을 요청하세요.
사용량으로 요금제 고르기 →준비됐다면 공식 개통 신청 ↗

4. 혼자 진행하기 어려울 때

본인인증이나 신분증 확인이 어렵거나, 미성년자·법인·외국인 여권으로 신청하려는 경우에는 가능한 개통 방법과 서류를 먼저 상담하세요. 공식 셀프개통 안내에는 해당 대상의 제한이 명시돼 있습니다.

모든 방문 개통은 사전 예약이 필수입니다. 사이트에서 희망 지역을 선택하고 카카오톡으로 방문 일정과 준비물을 확인하세요. 방문 장소와 시간은 예약 상담을 통해 안내합니다.

5. 자주 묻는 질문

본인인증 앱만 설치하면 준비가 끝난 건가요?

본인 명의 휴대폰을 준비하고, 안내된 인증 수단으로 실제 인증을 완료할 수 있어야 합니다. 카메라 작동 여부도 함께 확인하세요.

기존 번호를 계속 쓰려면 무엇을 선택하나요?

통신사를 옮기면서 번호를 유지하려면 번호이동을 선택합니다. 기존 회선의 상품만 바꾸는 요금제 변경과 구분하세요.

‘소진 후 최대 3Mbps’는 무슨 뜻인가요?

기본 데이터 사용 후에는 안내된 최대 속도로 데이터를 이용한다는 의미입니다. 데이터 용량인 GB·MB와 속도인 Mbps는 서로 다른 단위이며, 실제 속도는 이용 환경에 따라 달라집니다.

방문 상담 없이 바로 센터에 가도 되나요?

방수선불폰을 통한 방문 개통은 사전 예약 후 진행합니다. 희망 지역과 날짜를 카카오톡으로 알려주세요.
