## 사용자 제공 이미지 반영

- 프로젝트 루트에 추가된 카카오·토스·PASS·KB국민·신한 로고 5개를 인증서 질문에 이름과 함께 배치.
- 바로유심.jpg와 원칩 사진.jpg를 각각 kt-usim-user.jpg, lg-usim-user.jpg로 복사하여 이전 유심 이미지를 대체. 원본은 유지.
- 유심 보유 질문에도 제품 사진을 표시. 유심 없음 화면에서는 더 큰 사진과 준비완료 버튼 표시.
- 모바일 인증서 있음/없음 선택지를 같은 행의 두 열로 배치.
- 390px 모바일에서 가로 넘침 없음, 이미지 로딩 및 개통 링크 유지 확인.
- 아래의 기존 유심 출처 기록은 교체 전 시안에 대한 기록임.

- 인증서 있음 → 유심 질문 / 없음 → 기존 카카오톡 지점 안내.
- 유심 있음 → 기존 공식 개통 URL / 없음 → 인증 유심 제품 사진.
- 준비완료, 개통하러가기 → 기존 공식 개통 URL. 준비결과·모름 선택지는 없음.
- 홈페이지 원본과 운영 배포는 변경하지 않음. 상세·요금제 링크는 현재 로컬 페이지 사용.

- 판매점 표시는 사용자 첨부 원본을 그대로 복사함. authorized-store.png.

## 로고 생성 프롬프트

Use case: logo-brand. Create ONE polished Korean custom typography wordmark for a prepaid mobile activation website. Exact text only: "방수선불폰". Five Korean syllable blocks 방 / 수 / 선 / 불 / 폰, all must be distinctly readable in this order. Make the SECOND syllable "수" cleverly double as an UMBRELLA: the ㅅ upper component becomes a graceful domed umbrella canopy with 2 subtle scallops; the ㅜ component below retains its Korean crossbar and vertical stem, doubling as umbrella shaft. A tiny bend at the very bottom may suggest a handle but preserve immediate reading as 수, not 우 or 슈. Integrate it as a letter in the baseline, not an extra icon above a normal 수. Add at most two very small clean raindrop accents near the canopy to convey water protection. First two syllables 방수 vivid raspberry red (#f21c50); remaining 선불폰 deep charcoal (#22262b). Bold custom rounded geometric Gothic forms, refined kerning and consistent letter height. The umbrella treatment is tasteful, not cartoonish or a large illustration. Premium friendly trustworthy Korean mobile brand, not a plumbing service. Extremely crisp flat vector-like solid colors, no shadows, no gradient, no 3D, no texture. Only a single horizontal wordmark; no slogans, no badges, no other logos, no additional text, no presentation board. Tight composition with moderate safe padding, transparent background. The mark will be used at 210px width in a website header; design for readability.
